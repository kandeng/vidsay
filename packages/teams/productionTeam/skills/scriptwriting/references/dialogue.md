# 对白处理

- 对白承担性格与冲突，不承担信息灌输。角色不说双方都已知道的事。
- 每个角色的口吻要可区分：用词习惯、句子长短、回避的话题。同一场景内不超过必要角色数。
- 潜台词优先：人物想要 A 时说出来的往往是 B。黑幽默常来自人物严肃地说出荒诞的话，或荒诞处境里计较琐碎小事。
- 对白写进 envelope 的 dialogue 数组：role 是角色名（全片统一，不用"男/女"泛称），line 是台词原文。叙述性内容放 beats/summary，不要塞进 dialogue。
- 草稿里的直接引语尽量保留原句，改编时只做口吻与长度修剪；大幅改写要在报告的 changes 里说明。
- 时长敏感：3 分钟短片的台词总量控制在 250 字以内（中文口径），给画面和停顿留空间。
